# S04b API contracts and the demo responses: reviews

Commits `b68b741` and `05f3b3f` (architect, 2026-11-22). Checks: 892 Vitest and 84 node tests green; typecheck and `pnpm check` green; the H4 sweep finds 0 unresolved in the changed files.

## architect's report

1. **Schemas** (`packages/api-contract`): strict objects for every §5.1 area. They include:
   - `common`: SourceRef, SourcedValue, `Usage` in st with integers only, NotCheckedReason, and the `SectionResult` union;
   - `report`, with 11 checks and coverage of 11;
   - `investigations`, including `offerDomain`, the `Verdict`, questions, the library and follow-ups;
   - `events`, the §7.6 union;
   - `agents` status, plus `search`, `network`, `export` (open tier), `purpose`, `disputes`, `sources`, `settings` and `health`.

   `markets.ts` uses the shared SourceRef.
2. **`API_ROUTES`:** 27 routes. `docs/api/openapi.json` (OpenAPI 3.1) is generated from it, and `openapi.test.ts` fails when the file is stale.
3. **Acceptance 1:** valid and invalid samples for every schema. The invalid samples check that:
   - an empty `data` is refused;
   - `generatedBy: "ai"` is required on findings, explanations and follow-ups;
   - `coverage.total` can only be 11;
   - `entity_choice` has no default and no countdown;
   - no header names a natural person;
   - a blocked purpose is refused;
   - export holds the open tier only;
   - no investigation, agents or settings DTO has a field matching `/usd|cost|price|eur/i`;
   - a person row id is never an eid.
4. **`contractRoute`:** validates params, query and body before the service runs. A 400 names only the field path, never the value, and a blocked purpose returns `purpose_blocked`. A route with no service yet returns fixtures under `FINORA_DEMO=1` and `501 not_implemented` otherwise. `contract-routes.test.ts` covers:
   - the route table equals `API_ROUTES`;
   - every demo response is valid against its own schema;
   - the event stream resumes after `Last-Event-ID` with no gap.
5. **New error codes:** `agents_unavailable`, `entity_not_found`, `investigation_running`, `not_implemented` and `purpose_blocked`. Drafts exist in four languages, and the `errors` namespace is on the native-review list.

Demo: `FINORA_DEMO=1 pnpm dev`, then `curl http://127.0.0.1:3000/api/v1/companies/lv-00000000001`.
